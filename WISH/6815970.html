WISH DSL 速查表 (Cheat Sheet)

供 AI Agent 和开发者快速查阅关键字行为与副作用。

1. 关键字全集

关键字全称作用域 (Phase)逻辑关系副作用示例
reqRequire静态解析 (AST)AND (必须)强制拉取依赖包到环境req("python", "numpy>=1.20")
avaAvailable静态解析 (AST)OR (条件)如果条件不满足，当前包会被求解器丢弃ava("platform=linux")
banBan静态解析 (AST)NOT (冲突)如果目标包存在，当前包不可用ban("conflicting-lib")
xorExclusive OR静态解析 (AST)XOR (互斥)从列表中选且仅选一个加载xor("qt5", "qt6")
altAlternative静态解析 (AST)Fallback当目标包缺失时，当前包充当替身alt("openssl")
extExtension静态解析 (AST)Inject第二阶段解析时注入（需触发条件）ext("plugin@maya")
envEnviron动态执行 (Runtime)N/A修改当前进程的环境变量env("PATH").insert(bin_path)
aliasAlias动态执行 (Runtime)N/A注册 Shell 命令别名alias("ll", "ls -l")

2. 常见模式代码片

模式 A：跨平台依赖 (Cross-Platform Dependency)

错误写法:

if sys.platform == "win32":
    req("win32-api") # ❌ 错误！静态解析器会忽略 if，Linux 下也会抓取此依赖！

正确写法:

# 方案 1: 拆分包 (推荐)
# 创建 packages/my-lib/1.0.0.win/package.py 和 1.0.0.lin/package.py
# 分别使用 ava("platform=windows") 和 ava("platform=linux")

# 方案 2: 使用 ava (如果是一个包文件)
# 让 WISH 的求解器来处理平台判断
req("win32-api")
ava("platform=windows") # 只有在 Windows 平台，这个包才可用

模式 B：插件自动注入 (Auto-Injection)

# 在 render-plugin 包中：

# 仅当环境中存在 maya 时，此插件才会被加载
req("render-core")
ava("maya")

模式 C：环境变量优先级

# 高优先级（插队到最前）
env("PATH").insert("/opt/my/bin")

# 低优先级（追加到最后）
env("PATH").append("/usr/local/bin")

# 强制覆盖
env("MY_VER").setenv("1.0.0")

3. 调试指南

解析错误 (RESOLVE_ERROR):

  • 检查 ava 条件是否过于严苛。
  • 检查 req 是否形成了循环依赖。
  • 检查 ban 是否排除了必要的依赖。

扩展未生效 (PENDING_ERROR):

  • 检查 ext("pkg@trigger") 中的 trigger 包是否在最终解中。
  • 检查被扩展包的 ava 条件是否满足。

4. 执行部分：完整的 Python 能力

核心理解: package.py 不仅仅是配置文件，它分为两个部分：声明部分（AST 静态提取）和执行部分（完整 Python 运行时）。

4.1 双重结构

# ============ 声明部分 (AST 静态提取，进入图谱) ============
# 这些关键字会被 AST 解析器提取，用于依赖解析
# 不会在此时执行，而是用于构建依赖图

req("python>=3.9", "pytorch>=2.0")     # 依赖声明
ava("platform=linux", "cuda>=11.0")    # 可用条件
ban("tensorflow")                       # 冲突声明
xor("backend-a", "backend-b")          # 互斥约束
ext("flash-attn@cuda>=11.8")           # 条件扩展

# ============ 执行部分 (完整 Python，依赖解析后执行) ============
# 以下代码在包被选中后完整执行，拥有完整的 Python 能力

import os
import shutil
import subprocess
import urllib.request

# 环境变量设置
env("PATH").insert(os.path.join(this.root, "bin"))
env("PYTHONPATH").insert(this.root)
env("LD_LIBRARY_PATH").insert(os.path.join(this.root, "lib"))

# 条件逻辑
if os.path.exists("/opt/cuda"):
    env("CUDA_HOME").setenv("/opt/cuda")
    env("PATH").insert("/opt/cuda/bin")

# 首次安装处理
if this.init:
    # 创建目录
    os.makedirs(os.path.join(this.root, "cache"), exist_ok=True)
    
    # 复制配置文件
    config_src = os.path.join(this.root, "config.template")
    config_dst = os.path.expanduser("~/.config/myapp/config")
    if os.path.exists(config_src):
        os.makedirs(os.path.dirname(config_dst), exist_ok=True)
        shutil.copy(config_src, config_dst)

# 运行系统命令
subprocess.run(["ldconfig"], check=False)

# 下载资源
model_path = os.path.join(this.root, "models", "default.bin")
if not os.path.exists(model_path):
    urllib.request.urlretrieve(
        "https://models.example.com/default.bin",
        model_path
    )

# 任何 Python 能做的事情都可以在这里做

4.2 this 上下文对象

属性类型说明示例值
this.namestr当前包名"pytorch"
this.tagsstr当前版本标签"2.0.1.lin.0"
this.rootstr包安装根目录"/packages/pytorch/2.0.1.lin.0"
this.initbool是否首次激活（刚下载）True / False

4.3 env() 操作方法

方法行为示例
.insert(path)插入到环境变量头部（高优先级）env("PATH").insert("/opt/bin")
.append(path)追加到环境变量尾部（低优先级）env("PATH").append("/usr/bin")
.setenv(value)覆盖整个环境变量env("MY_VAR").setenv("value")
.remove(path)从环境变量中移除指定路径env("PATH").remove("/old/path")
.unload(prefix)移除所有以 prefix 开头的路径env("PATH").unload("/opt/old")
.getenv()获取当前环境变量值current = env("PATH").getenv()
.envlist()获取环境变量列表形式paths = env("PATH").envlist()

4.4 执行部分的常见用途

# 用途 1: 动态路径构建
lib_path = os.path.join(this.root, "lib", "python3.10", "site-packages")
env("PYTHONPATH").insert(lib_path)

# 用途 2: 平台特定配置（执行时判断，非声明时）
import platform
if platform.system() == "Windows":
    env("PATH").insert(os.path.join(this.root, "win32", "bin"))
else:
    env("PATH").insert(os.path.join(this.root, "bin"))
    
# 用途 3: GPU 检测与配置
def detect_cuda():
    return os.path.exists("/usr/local/cuda") or os.environ.get("CUDA_HOME")

if detect_cuda():
    env("CUDA_VISIBLE_DEVICES").setenv("0,1,2,3")

# 用途 4: 自动修复权限（首次安装）
if this.init:
    bin_dir = os.path.join(this.root, "bin")
    for f in os.listdir(bin_dir):
        os.chmod(os.path.join(bin_dir, f), 0o755)

# 用途 5: 注册命令别名
alias("py", "python")
alias("pt", "python -m torch.distributed.launch")

4.5 声明 vs 执行：关键区别

特性声明部分 (req/ava/ban/...)执行部分 (其他代码)
解析方式AST 静态提取Python exec() 执行
执行时机依赖解析阶段（包被选中前）环境激活阶段（包被选中后）
进入图谱✓ 是（用于血缘追踪）✗ 否
可用条件逻辑✗ 否（必须静态）✓ 是（完整 Python）
目的声明包之间的关系配置运行时环境

重要: 声明部分（req/ava/ban/xor/alt/ext）必须是静态的，不能放在 if/else/try 块中。因为它们需要被 AST 解析器静态提取，用于在代码执行前构建依赖图。
